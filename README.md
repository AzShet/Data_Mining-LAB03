# Data_Mining-LAB03

This repository contains materials for Data Mining Lab 03. The project has been structured to separate concerns and improve maintainability.

## Project Structure

The repository is organized as follows:

-   `data/`: Contains data files used and generated by the project.
    -   `DATA_FORMATEADA.csv`: The primary processed data output by the main script.
-   `src/`: Contains the Python source code.
    -   `main.py`: The main script that orchestrates the data loading, preprocessing, analysis, and saving.
    -   `data_utils.py`: A utility module containing functions for data loading, preprocessing, and saving operations, used by `main.py`.
    -   `GLAB03-RUELAS.ipynb`: The original Jupyter Notebook from which the Python scripts were derived. This can be used for reference or further exploratory analysis.
-   `tests/`: Contains test files for the project.
    -   `test_main.py`: Includes tests to ensure `src/main.py` runs correctly and produces the expected output.
-   `car_evaluation_data.xlsx`: An Excel file generated by `src/main.py` containing the initial combined dataset.

## Running the Main Script

The main script processes the car evaluation dataset, performs various data manipulations, and saves the output.

To run the main script:

1.  Ensure you have Python installed.
2.  Install necessary dependencies. While `ucimlrepo` is handled within the script, you might need `pandas` and `numpy` if not already part of your Python environment. These are standard data science libraries.
    ```bash
    pip install pandas numpy
    ```
3.  Navigate to the root directory of the project in your terminal.
4.  Execute the script using Python:
    ```bash
    python src/main.py
    ```
    This will:
    - Fetch the Car Evaluation dataset.
    - Perform preprocessing steps defined in `src/data_utils.py`.
    - Save the processed data to `data/DATA_FORMATEADA.csv`.
    - Save an Excel version to `car_evaluation_data.xlsx` in the root directory.
    - Print various data exploration outputs to the console.

## Running Tests

Tests are provided to verify the functionality of the main script. `pytest` is used as the testing framework.

To run the tests:

1.  Ensure you have Python and `pytest` installed.
    ```bash
    pip install pytest
    ```
2.  Navigate to the root directory of the project in your terminal.
3.  Run `pytest`:
    ```bash
    pytest
    ```
    This will discover and run the tests defined in the `tests/` directory (e.g., `tests/test_main.py`). The tests will check if the main script executes without errors and produces the expected output files.

## Key Files

-   **`src/main.py`**: This is the entry point of the application. It uses functions from `src/data_utils.py` to perform its tasks, including loading data, preprocessing, some analysis (like timing operations, showing data snippets), and saving results.
-   **`src/data_utils.py`**: This module centralizes data-related operations. It includes functions for fetching the dataset from the UCI ML Repository, combining features and targets, saving data to Excel and CSV formats, and various preprocessing steps like changing data types and renaming categories/columns.
-   **`tests/test_main.py`**: Contains automated tests for `src/main.py`. It verifies that the script runs successfully and that output files are generated as expected.
-   **`src/GLAB03-RUELAS.ipynb`**: The original Jupyter Notebook. It can be useful for understanding the step-by-step development process and for interactive data exploration.
-   **`data/DATA_FORMATEADA.csv`**: The main output data file after processing.
-   **`car_evaluation_data.xlsx`**: An Excel output of the raw combined data, saved in the project root.
